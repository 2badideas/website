Inter: Latin variable normal WOFF2 from @fontsource-variable/inter 5.3.0.
Source: https://cdn.jsdelivr.net/npm/@fontsource-variable/inter@5.3.0/files/inter-latin-wght-normal.woff2
Upstream: https://github.com/rsms/inter
License: inter/LICENSE.txt (SIL Open Font License 1.1).
Inter characters outside the Latin subset use the existing Arial/sans-serif fallback.

Downloaded October 28, 2026. Both fonts are served locally via css/styles.css.

Grandstander: unmodified variable normal TTF from Google Fonts.
Source: https://raw.githubusercontent.com/google/fonts/main/ofl/grandstander/Grandstander%5Bwght%5D.ttf
Upstream: https://github.com/Etcetera-Type-Co/Grandstander
License: grandstander/LICENSE.txt (SIL Open Font License 1.1).
Weight range: 100-900.

Nunito: unmodified variable normal TTF from Google Fonts.
Source: https://raw.githubusercontent.com/google/fonts/main/ofl/nunito/Nunito%5Bwght%5D.ttf
Upstream: https://github.com/googlefonts/nunito
License: nunito/LICENSE.txt (SIL Open Font License 1.1).
Weight range: 200-1000.

Downloaded October 30, 2026. Grandstander and Nunito are served locally by
games/sap-and-survive/index.html, including its canvas text. No runtime
Google Fonts connection is required.
